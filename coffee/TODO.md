# 清单

V1 的目标:只要 x86-64,系统 `cc` 做链接器,不用 LLVM,不用 Rust 也能构建和测试。

## 已完成

- [x] 机器码后端是默认,LLVM 已移除
- [x] 种子构建:只用 `cc` 就能得到 `coffee2` 和 `tea`
- [x] `tea test`:每个测试独立目录,并行,600 秒超时
- [x] 兼容测试:627 个用例全部通过
- [x] stage0(Rust 编译器)自举得到不动点
- [x] 嵌套 fn、匿名 fn、模块级 `let`
- [x] 同名的嵌套 `class` 出现在两个函数里:驱动在前端之前把重名的改成 `名字__n<函数号>`(`driver/src/nested.cf`)
- [x] 复合赋值 `+=` `-=` `*=` `/=` `//=` `%=`(解析成 `t = t op v`)
- [x] f-string 的 `{}` 里可以是任意表达式,类型 `str`、整数、浮点、`bool`
- [x] `use f as g in m`:展开时在本文件里把 `g` 换成 `f`(`driver/src/alias.cf`)
- [x] 或模式里绑定变量(各分支同名同类型,穷尽性检查算上每个分支)
- [x] 尾表达式返回、`for` 的各种形式、`&` 取址、或模式、类模式、f-string

## 编译器性能

- [ ] 二元运算直接用寄存器操作数(现在都先装进 rax/rcx)
- [ ] 自举编译约 17 秒,找出热点
- [ ] 增量编译:没改的文件复用 `.o`

## 语言缺口

- [ ] 全局变量只支持标量;`str`、类、数组的全局变量
- [ ] f-string 的格式说明(`{x:5}`、小数位数)、`{{` 转义、表达式里的字符串字面量
- [ ] 模块别名 `use m as a`(只解析,没有语义)
- [ ] `obj.assign` 对需要释放的字段(`str`、类)
