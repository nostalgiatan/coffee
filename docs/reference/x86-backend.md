# x86-64 后端参考

文件:`ir/src/asm.cf`(指令编码)、`ir/src/elf.cf`(目标文件)、`ir/src/gen.cf`(状态 `Gen` 和各目标共用的部分)、`ir/src/gen_dbg.cf`(行表),以及 x86-64 专属的 `gen_x86_regs.cf`(寄存器、帧、边上的移动)、`gen_x86_call.cf`(调用约定)、`gen_x86_isel.cf`(每个操作的指令)、`gen_x86_vec.cf`(向量循环)、`gen_x86_fun.cf`(一个函数和目标文件)。代码生成器是自由函数 `g_*(g: &Gen, ...)`,不是 `Gen` 的方法:Coffee 的方法只能写在类里面,一个类不能分在几个文件;改成自由函数以后,新增一个目标是新增一组 `gen_<目标>_*.cf`。选择理由见 [后端的取舍](../explanation/backend-choices.md)。

## 目标文件

`write_elf` 写出可重定位的 ELF64,节依次是:空节、`.text`、`.rodata`、`.rela.text`、`.note.GNU-stack`、`.symtab`、`.strtab`、`.shstrtab`。

- `.rodata` 开头是 256 字节的零,供 `Undef` 聚合读取;字符串字面量接在后面,以 NUL 结尾。
- 符号 1 是 `.rodata` 节符号,用户符号从 2 开始。
- 对函数的调用用 `R_X86_64_PLT32`,对 `.rodata` 的引用用 `lea rip` 加 `R_X86_64_PC32`。已定义和未定义(外部)的函数都走符号。

## 栈帧

以 rbp 为基准:

| 位置 | 内容 |
|---|---|
| `[rbp-8]` | 返回聚合的函数收到的隐藏指针 |
| `[rbp-16-8k]` | 第 k 个被保存的寄存器 |
| 其下 | 每个未进寄存器的值一个 8 字节对齐的位置;聚合按内存布局;`Slot` 的区域 |
| 最下 | 边复制用的暂存区 |

帧大小向上取整到 16。

## 寄存器

| 用途 | 寄存器 |
|---|---|
| 值的住所(被调用者保存) | rbx, r12, r13, r14, r15 |
| 运算的临时 | rax, rcx, rdx, rsi, rdi, r8, r9, r10, r11 |
| 间接调用的地址 | r11 |

序言保存用到的住所寄存器,每个 `Ret` 之前恢复。调用点不保存任何东西。

## 寄存器分配

只管标量(整数、指针,浮点按位放在通用寄存器里)。步骤:

1. 对每个块做活跃性数据流,得到每个值的活跃区间(块顺序上的一个区间)。
2. 按区间起点做线性扫描。五个寄存器都占用时,把权重最低的那个值整个放回栈帧。权重是使用次数乘以 8 的循环深度次方(上限 4096)。
3. 块参数的拷贝按顺序进行;当后面的参数会读一个已经被覆盖的寄存器,或者参数本身就是目标块的参数时,经暂存区拷贝。

没有区间拆分。聚合、`Slot`、常量不进寄存器:常量和字符串地址每次使用时重新生成。

## 调用约定

System V:

- 整数和指针依次用 rdi, rsi, rdx, rcx, r8, r9;浮点用 xmm0 到 xmm7;其余从右到左入栈,栈在调用前补齐到 16 字节。
- 聚合参数传指向调用者栈帧中那份数据的指针。
- 返回聚合的函数,隐藏指针放在第一个整数寄存器里。
- 可变参数的 C 调用把 al 设为用到的 xmm 寄存器个数。

## 指令选择

直接而且不精:每个运算把操作数装进 rax 和 rcx,算完写回住所。`Switch` 是一串比较。`CondBr` 先 `setcc` 再 `test`。这些以后可以融合,见 [后端的取舍](../explanation/backend-choices.md)。

## 限制

- 只有 x86-64。
- 输出的目标文件靠 `clang`(或任何系统链接器)链接。
- 浮点只有加减乘除、取余(调用 `fmod`)、比较和转换,经通用寄存器和 xmm0、xmm1 中转。
