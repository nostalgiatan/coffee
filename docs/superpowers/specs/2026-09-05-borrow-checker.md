# Coffee 过程内借用检查（2026-09-05）

状态：**已实现**（`src/types/borrow.rs`，由 `TypeChecker` 驱动）。

## 范围

- 地点（`Place`）包括：变量、字段链 `p.x`（可嵌套 `p.x.y`）、索引 `a[i]`。`&x` / `&mut x`，以及 `&p.x` / `&a[i]` 等同路径。
- 重叠地点按前缀保守冲突：`p` 与 `p.x`、`a` 与 `a[i]` 视为同一冲突集合；不同字段 `p.x` 与 `p.y` 不重叠。索引不区分下标（`a[i]` 与 `a[j]` 重叠）。
- 函数内：共享 XOR 可变（同一重叠集合上可有多个 `&`，或一个 `&mut`，不可并存）。
- 借用期间禁止对该地点（含重叠根）`mv` / `rm` / 赋值；可变借用期间禁止当值使用该地点。
- 命名 `&`/`&mut` 绑定：loan 活到该绑定在函数剩余部分的最后一次使用之后，或声明它的 `if`/`while` 体结束。临时借用（如 `foo(&x)`）在语句结束失效。
- 返回指向**非参数局部变量**的引用是 E400。
- 代码生成：`&x` 取 alloca 指针，`*r` 按注解的 pointee 类型 load。
