# Standard library Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans. Do **not** git commit. Do **not** bump version.

**Goal:** Coffee std package (`library/std`), embed it in the `coffee` binary, `coffee std install`, compile prepends that import root; `print`/`exit` and `IntBuf` follow the hard rules in the spec.

**Architecture:** One package, files `sys.cf` (only `of c`) / `io.cf` / `mem.cf` / `std.cf`. Rust `build.rs` embeds the tree. `compiler::pkg::std_path` finds install/dev/env. `ProjectBuilder` and single-file pipeline prepend `src/` of that package.

**Tech Stack:** Existing compiler + pkg resolve; `build.rs` + generated embed; no new crate unless `walkdir` is painful (prefer `std::fs` in build.rs).

## Global Constraints

- Spec: `docs/superpowers/specs/2026-09-06-stdlib-design.md`
- Do **not** git commit. Do **not** bump `Cargo.toml` `[package].version`.
- Dual `foo.rs` + `foo/` modules forbidden.
- `flock /data/data/com.termux/files/home/coffee/.superpowers/sdd/cargo.lock cargo test --offline --test <name> -- --test-threads=1`
- Binary: `--test-mode`.
- `of c` only in `library/std/src/sys.cf`.
- Selective import is functions only; `IntBuf` via `use mem`.
- No `printf`. `strlen` only inside sys wrappers used for `write`.

### Task 1: `library/std` Coffee sources

**Files:** Create all of `library/std/**` listed above.

**Produces:** Package name `std`. Wrappers and `print`/`IntBuf` as in the spec.

- [ ] **Step 1:** Write `library/std/coffee.toml`:

```toml
[package]
name = "std"
version = "0.1.0"
description = "Official Coffee standard library (ships with the compiler)"
```

- [ ] **Step 2:** Write `sys.cf` — only `of c` file; wrappers `sys_malloc`, `sys_free`, `sys_memcpy`, `sys_write`, `sys_exit`, `sys_strlen`. libc `write` is `fn write(fd: int, buf: object, n: int) => int` (use `int` 8-byte; if C ABI mismatch on Android, `int(4)+` for fd and n — match existing `tests` that call C). Check `tests/imports_tests.rs` / libc defaults in `src/semantic` for `write`/`malloc` signatures. If `write` is not a builtin, declare via `use write in libc of c` and keep signatures compatible with inkwell i64 or i32 as the rest of the compiler does for libc.

- [ ] **Step 3:** Write `io.cf` with `fn write_fd(fd: int, s: str) => void` using `sys_write` + `sys_strlen`.

- [ ] **Step 4:** Write `std.cf`:

```coffee
use write_fd in io
use sys_exit in sys

fn print(s: str) => void:
    write_fd(1, s)

fn eprint(s: str) => void:
    write_fd(2, s)

fn exit(code: int) => void:
    sys_exit(code)
```

Nested `use` must appear at the top of the file (parser: all `use` before functions).

- [ ] **Step 5:** Write `mem.cf` `class IntBuf` with `new` / `push` / `get` / `length`. `fn new` required so the instance is heap-allocated (compiler malloc). Grow with `sys_malloc`/`sys_memcpy`/`sys_free`. `get` OOB returns 0. No `raise`. Move-only (do not clone buf).

- [ ] **Step 6:** Failing-then-passing tests in `tests/std_lib_tests.rs` (include `tests/common/mod.rs`). Set `COFFEE_STD` to `<repo>/library/std`. Project with `src/main.cf`:

```coffee
use print in std

fn main() => int:
    print("hello-std\n")
    return 0
```

`--bin` or `--jit`; assert stdout contains `hello-std`. Second test `use mem` + IntBuf push 1,2,3 get 1 == 2, length 3; print the get via `print` or return it.

Until Task 2 wires implicit std, tests **must** put std on the path: either `COFFEE_STD` consumed by a stub, or:

```toml
[dependencies.packages.std]
path = "../../library/std"
```

relative to the temp project — **use an absolute path** to the repo `library/std` in the test helper so it does not depend on Task 2.

- [ ] **Step 7:** `flock … cargo test --offline --test std_lib_tests -- --test-threads=1`

**Do not** edit `src/main.rs` except if a libc signature must be declared in compiler builtins (prefer not).

### Task 2: Embed, `coffee std install`, compile prepend, init

**Depends on:** Task 1 files existing (embed walk `library/std`).

**Files:** `build.rs`, `src/compiler/pkg/std_fs.rs`, `pkg/mod.rs`, `builder.rs`, CompilerConfig import_paths in `src/compiler.rs` / `src/main.rs` single-file, `init_project`, `print_usage`, `tests/std_install_tests.rs`, docs.

**Produces:**

```rust
pub fn std_package_root() -> Result<PathBuf, String>;
pub fn extract_embedded_std(dest: &Path) -> Result<(), String>;
pub fn std_import_root() -> Result<PathBuf, String> {
    Ok(super::resolve::import_root_for(&std_package_root()?))
}
```

Lookup: `COFFEE_STD` (must contain `coffee.toml`) → `$XDG_DATA_HOME/coffee/std` → `$HOME/.local/share/coffee/std` → walk up from `std::env::current_exe()` and cwd for `library/std/coffee.toml` → Err with `run coffee std install`.

- [ ] **Step 1:** `build.rs` walks `library/std`, copies files into `OUT_DIR/std_embed/` and writes a `std_embed.rs` listing `(&str, &[u8])` via `include_bytes!`. `std_fs.rs` `include!(concat!(env!("OUT_DIR"), "/std_embed.rs"))` or a function `embedded_std_files() -> &'static [(&'static str, &'static [u8])]`.

- [ ] **Step 2:** `extract_embedded_std` writes those relative paths under `dest`.

- [ ] **Step 3:** CLI: after `init`/`fetch` parse, `args[1] == "std"` and `args[2] == "install"`. Optional dest: `std install <dir>` overrides default (still `--test-mode` anywhere). Print installed root path.

- [ ] **Step 4:** `ProjectBuilder` after `resolve_packages`: if no key `std` in packages, `insert(0, std_import_root()?)`. Single-file compile in `main.rs`: same prepend on `CompilerConfig.import_paths`.

- [ ] **Step 5:** `init` `src/main.cf`:

```coffee
use print in std

fn main() => int:
    print("Hello, Coffee!\n")
    return 0
```

Toml comment: bundled std; `coffee std install` if missing. Do not write `path =` to std.

- [ ] **Step 6:** Tests `tests/std_install_tests.rs`: temp `COFFEE_STD` empty → install → files exist → compile a tiny project **without** packages.std path, using only `COFFEE_STD`. `print_usage` contains `std install`.

- [ ] **Step 7:** Docs: SYNTAX std subsection, EN/ZH README, CLAUDE.md, usage.

- [ ] **Step 8:** `flock … cargo test --offline --test std_install_tests --test std_lib_tests -- --test-threads=1`
